kali-invoice-service

Servicio encargado de proveer las funcionalidades de facturación necesarias para la operación del sistema, incluyendo creación, consulta, listado y actualización de documentos de facturación.

http://localhost:8081

Pendiente por completar

21 de mayo de 2026

Nombre del endpoint: Crear factura
Método HTTP: POST
URL completa: http://localhost:8081/api/v1/invoices/
Ruta: /api/v1/invoices/
Descripción: Crear un nuevo documento de facturación.
Requiere autenticación: No
Headers requeridos:
- Idempotency-Key: <clave única>
Parámetros de ruta: No aplica
Parámetros de query: No aplica
Body JSON de ejemplo:
{
  "customer_id": "cust-123",
  "issue_date": "2026-05-03T10:00:00Z",
  "due_date": "2026-05-10T10:00:00Z",
  "items": [
    {
      "item_id": "item-xyz789",
      "quantity": 5,
      "unit_price": 100.00,
      "taxes": [
        { "code": "IVA", "rate": 19, "kind": "DEBIT" },
        { "code": "DESCUENTO", "rate": 5, "kind": "CREDIT" }
      ]
    }
  ]
}
Respuesta exitosa esperada:
{
  "id": "inv-abc123",
  "customer_id": "cust-123",
  "issue_date": "2026-05-03T10:00:00Z",
  "due_date": "2026-05-10T10:00:00Z",
  "status": "PENDING",
  "subtotal": 500.00,
  "tax_total": 65.00,
  "total": 565.00,
  "items": [ ... ],
  "created_at": "2026-05-03T10:00:00Z"
}
Respuesta de error esperada:
{
  "message": "customer_id is required"
}
Código HTTP esperado: 201
Observaciones: Requiere header Idempotency-Key único por solicitud. No requiere autenticación.
